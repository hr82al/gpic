# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

`gpic` — генератор обоев для рабочего стола. Картинка генерируется **локально**
через FLUX.1-schnell на движке `stable-diffusion.cpp` (родственник `llama.cpp`,
та же библиотека `ggml`). Никаких удалённых API, ключей и лимитов.

Репозиторий намеренно состоит из четырёх текстовых файлов. Всё тяжёлое —
движок в `build/` и веса в `models/` — создаётся скриптом и лежит в `.gitignore`.

| Файл | Роль |
|---|---|
| `gpic.py` | вся логика: аргументы, промпт, вызов движка, вывод |
| `setup.sh` | развёртывание с нуля: пакеты, сборка, веса, лаунчер |
| `README.md` | инструкция для пользователя |
| `.gitignore` | не пускает гигабайты и секреты в репозиторий |

## Команды

```sh
./setup.sh                    # развернуть всё с нуля (идемпотентно)
python3 gpic.py -r 512x512    # быстрый прогон без установки лаунчера
gpic                          # после установки, из любого каталога
rm -rf build models ~/.local/bin/gpic   # полный откат
```

Тестов нет: логика тонкая, а единственная содержательная операция —
запуск внешнего движка.

## Что важно знать, прежде чем править

- **`gpic.py` — только стандартная библиотека.** Никакого `pip install`:
  утилита должна работать сразу после `git clone`. Не добавляй `Pillow`
  и подобное — нужный размер выдаёт сам движок, обрабатывать картинку
  в Python не требуется.
- **FLUX — четыре файла, а не один.** Диффузионная модель, текстовый энкодер
  T5, CLIP-L и VAE. Без любого из них движок не запустится.
- **`--cfg-scale` обязан быть 1.0.** FLUX.1-schnell дистиллирована под малое
  число шагов и не использует classifier-free guidance. Другое значение
  испортит результат.
- **Размеры кратны 16.** `align16()` в `gpic.py` округляет запрошенное
  разрешение; для 1920x1200 округление не нужно, но для произвольного —
  да.
- **Целевое железо — встроенная Radeon 780M**: 4 ГБ выделенной видеопамяти
  плюс ~14 ГБ через GTT. На APU выход за пределы VRAM не штрафуется, как на
  дискретной карте: GTT — та же системная память. Поэтому квантование
  Q5_K_S выбрано по качеству, а не из-за нехватки памяти.
- **ROCm не используется.** Для gfx1103 он официально не поддерживается;
  Vulkan работает без костылей. При неудаче сборки `setup.sh` откатывается
  на режим CPU.
- **Разрешение экрана читается из `/sys/class/drm`, а не через `xrandr`** —
  сессия Wayland, где `xrandr` пуст.

## История

Первая версия была на Rust и ходила в удалённый API Pollinations, дорисовывая
результат Lanczos до размера экрана. От неё отказались: анонимный тир
Pollinations заперт на слабой модели с бюджетом 0.59 Мп, а проверенные
альтернативы (Gemini, Together AI) оказались платными. Локальная генерация
сняла вопрос целиком. Код той версии остался в истории git.
