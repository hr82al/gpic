## Архитектура

`gpic` — консольная утилита (Rust, edition 2024), которая генерирует случайную (или заданную промптом) картинку через бесплатный сервис Pollinations и подгоняет её под разрешение монитора, чтобы использовать как обои рабочего стола.

`main.rs` — тонкий слой связки: разбирает аргументы, решает разрешение/промпт/seed по умолчанию, вызывает модули по порядку и печатает ход выполнения. Логики он не содержит — она живёт в шести модулях:

- `cli` — аргументы командной строки (`clap`): промпт, разрешение (`ШИРИНАxВЫСОТА`), seed, путь к файлу.
- `screen` — определение разрешения монитора через sysfs; при неудаче тихо возвращает 1920×1200.
- `prompt` — генератор случайного промпта из встроенных списков сюжетов/стилей.
- `provider` — HTTP-запрос к `image.pollinations.ai`, сборка URL, повтор с другим seed при сбое.
- `resize` — масштабирование полученной картинки до точного целевого разрешения.
- `output` — путь по умолчанию с таймстампом, определение формата по расширению, сохранение файла.

Ключевой факт: API Pollinations соблюдает соотношение сторон, но не абсолютный размер — отдаёт картинку с фиксированным бюджетом около 0.59 Мп (например, 1920×1200 превращается в ~971×607). Поэтому `resize::to` всегда прогоняется после `provider::fetch`, локально, уже на клиенте.

Ещё один нюанс: сервис принимает seed не больше `i32::MAX` (2147483647), хотя тип поля — `u32`; `cli` ограничивает явный ввод этим диапазоном, а `main` генерирует случайный seed в тех же границах.
