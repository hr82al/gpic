# gpic

Генератор обоев для рабочего стола. Одна команда без аргументов кладёт в текущий
каталог свежую картинку под разрешение твоего монитора.

Всё считается **локально**, на твоей машине: FLUX.1-schnell через
[stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp).
Ни ключей, ни аккаунтов, ни лимитов, ни прокси. Модель работает с любым размером,
кратным 16, поэтому картинка рождается сразу в нужном разрешении — она не
растягивается из чего-то меньшего.

## Установка

```sh
git clone https://github.com/hr82al/gpic
cd gpic
./setup.sh
```

`setup.sh` делает всё сам: доставляет недостающие системные пакеты, собирает
движок, качает веса и ставит лаунчер в `~/.local/bin/gpic`. Скрипт идемпотентен —
если загрузка оборвалась, просто запусти его снова, он продолжит с места остановки.

В конце он проводит контрольную генерацию и печатает, сколько она заняла, чтобы
ты сразу знал, чего ждать от своего железа.

Если GitHub или Hugging Face медленно отдают, запусти установку через прокси —
`curl` и `git` читают стандартные переменные окружения:

```sh
HTTPS_PROXY=http://127.0.0.1:8888 ./setup.sh
# или, если в системе есть обёртка:
with-vpn ./setup.sh
```

## Использование

```sh
gpic                                        # картинка под разрешение экрана
gpic -r 2560x1440                           # своё разрешение
gpic -p "зимний лес на рассвете"            # свой промпт
gpic -s 319553386                           # повторить конкретную картинку
gpic wall.png                               # своё имя файла
gpic -r 3840x2160 -p "ночной город" ~/w.png # всё сразу
```

Без `-p` промпт собирается случайно из трёх списков (сюжет, свет, стиль).
Без имени файла получается `gpic-ГГГГММДД-ЧЧММСС.png` в текущем каталоге.
Использованный seed печатается — по нему картинку можно воспроизвести.

## Что где лежит

| Путь | Содержимое | В git |
|---|---|---|
| `gpic.py` | вся логика | да |
| `setup.sh` | развёртывание | да |
| `build/` | исходники и бинарник движка | нет |
| `models/` | веса FLUX, около 12 ГБ | нет |

Тяжёлое намеренно не попадает в репозиторий — в нём только текстовые файлы.

## Требования

- Linux, Python 3 (только стандартная библиотека, `pip install` не нужен)
- около 15 ГБ свободного места
- видеокарта с Vulkan желательна, но не обязательна: если сборка с Vulkan не
  удастся, `setup.sh` сам пересоберёт движок в режиме CPU

## Удаление

```sh
rm -rf build models ~/.local/bin/gpic
```

## Оговорка про скорость

Генерация на встроенной графике измеряется минутами, а не секундами, и время
растёт пропорционально числу пикселей. Это плата за то, что всё считается
локально и бесплатно. Точную цифру для твоей машины покажет `setup.sh`.
